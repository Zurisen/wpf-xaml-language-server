# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the code. Harassment,
insults and personal attacks are not tolerated in issues, pull requests, discussions or any other project space.

To report unacceptable behavior, contact the maintainer privately through GitHub
([@Zurisen](https://github.com/Zurisen)). Reports are handled confidentially. The maintainer may remove comments
and block participants who break these rules.
